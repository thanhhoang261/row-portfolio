Chào mừng bạn đến với blog của mình!

## Vì sao có blog này

Viết giúp mình hệ thống lại kiến thức. Mỗi bài là một ghi chép nhỏ về thứ mình vừa học hoặc vừa làm.

## Nó hoạt động thế nào

Mỗi bài viết là một file `.mdx` nằm trong repo Git. Mình viết trên giao diện web (Keystatic), bấm lưu và nó tự commit — nên Git chính là bản backup.

```ts
const greeting = "Xin chào thế giới";
console.log(greeting);
```

Hẹn gặp lại ở các bài sau.
